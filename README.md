
# Online Bookstore SQL Data Analysis

## Project Overview

A SQL project using PostgreSQL to analyze bookstore data, including books, customers, orders, and sales.

## Tools Used

* PostgreSQL
* pgAdmin 4
* SQL

## Dataset

* `books.csv`
* `customers.csv`
* `orders.csv`

Each dataset contains 500 rows.

## SQL Concepts

* SELECT, WHERE, ORDER BY
* INNER JOIN and LEFT JOIN
* GROUP BY and HAVING
* Aggregate Functions
* Subqueries
* COALESCE

## Project Highlights

* Completed 20 SQL queries.
* Analyzed book sales and customer orders.
* Calculated total revenue and remaining stock.
* Identified frequently ordered books and high-spending customers.
